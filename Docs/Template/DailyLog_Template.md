# 작업 일지

> 1. 일일 단위 새 브랜치 생성 `document-이니셜-DailyLog-Register`
> 2. `Docs/DailyLog`에 작성된 `DailyLog_MMDD.md` 파일 넣기
> 3. `[Docs] MMDD 작업일지`, 설명 추가해서 커밋
> 4. PR 등록 시 `Reviewers`, `Assignees` 에 본인 지정
> 5. 둘 다 들어가 있는지 확인 후 PR 올리기 
> 6. 오전에 작성, 오후에 PR 올리기. 오전이 안 될 경우 오후에 작성 & 커밋
