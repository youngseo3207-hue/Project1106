# 개인 그라운드 룰

## 자료 관리

#### (1) SLACK, DISCORD, Notion

> 노션은 사용하지 않는다

#### 1. SLACK

- 하루 일지 작성 알람 전송용
- 별도 채널 개설 후 외부자료와 레퍼런스 관리

#### 2. DISCORD

- 외부자료 레퍼런스 임시 저장. 저장 된 자료는 슬랙에 편집 후 업로드

## 일정

#### 작업 시간

#### 1. 개인별

- 학원에 있는 시간은 작업 시간

| 이름 | 평일 | 주말 |
| --- | --- | --- |
| 공영서 | `20:00 - 00:00` | `12:00 - 20:00` |

#### (2) 일일 계획

#### 1. 평일

| 오전 | 오후 |
| --- | --- |
| `09:30` | `17:00` |
- 오전 : 작업 현황 상기 목적으로 방향성 및 하루 목표 작업량 생각
- 오후 : 진행 된 작업의 현황을 확인, 기능을 어떻게 나눌지 생각(기능 구현, 업무 진행 등)

#### 2. 주말

| 주말 |
| --- |
| `21:00` |
- 주말은 작업 진척도를 확인하는 정도로 진행
- 필요 시 작업 시간 추가 확보

## 자료 형식

#### (1) 마크다운 문서명

- Github 에 올라가는 문서는 **영문 PascalCase** 로 작성한다 (한글 파일명 깨짐 방지)

| 문서 종류 | 형식 | 예시 |
| --- | --- | --- |
| 날짜가 필요없는 문서 | `문서제목` | `GroundRules.md` |
| 날짜가 필요한 문서 | `MMDD_문서제목` | `1225_Presentation.md` |
| 작업일지 | `MMDD_작업일지` | `1225_일지.md` |
| 일일회고 | `MMDD_일일회고` | `1225_회고.md` |
| 양식 | `내용_Template` | `DailyLog_Template.md` |

#### (2) 스크립트 명

| 스크립트 형식 | 형식 | 예시 |
| --- | --- | --- |
| 인터페이스 | `I인터페이스명` | `IDamageable.cs` |
| 클래스 | `PascalCase` | `MyClass.cs` |
| 추상클래스 | `추상클래스명Base` | `MonsterBase.cs` |
| 싱글톤 | `싱글톤명Manager` | `GameManager.cs` |

#### (3) 공유 파일 명

| 종류 | 형식 | 예시 |
| --- | --- | --- |
| 파일 | `날짜_내용` | `0923_TURRET.zip` |
| 양식 | `내용_양식` | `오류보고서_양식.docs` |
| 사고 동영상 | `ERROR_내용.mp4` | `ERROR_총알장전이안돼요.mp4` |
