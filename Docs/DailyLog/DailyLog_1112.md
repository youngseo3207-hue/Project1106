# 업무 일지

> 1. 일일 단위 새 브랜치 생성 `document-이니셜-DailyLog-Register`
> 2. `Docs/DailyLog`에 작성된 `MMDD.md` 파일 넣기
> 3. `[Docs] MMDD 작업일지` 커밋
> 4. PR 등록 시 `Reviewers`, `Assignees` 에 본인 지정
> 5. 둘 다 들어가 있는지 확인 후 PR 올리기 
> 6. 오전에 작성, 오후에 PR 올리기

- **작성자** : 공영서
- **날짜** : 2026-11-12 (목요일)
- **제목양식** : `1112_YS`
